กฤตยชญ์ กุลกลางดอน

ผู้สมัครตำแหน่ง Project Coordinator (เจ้าหน้าที่ประสานงานโครงการ)

มีประสบการณ์ประสานงานและติดตามงานในโครงการภาครัฐ จัดทำรายงานส่งต่อผู้รับผิดชอบ และสร้างเครื่องมือช่วยงานด้วย Google Apps Script เพื่อลดงานเอกสารที่ทำซ้ำ

ป.ตรี รัฐศาสตร์

เกี่ยวกับฉัน

มีพื้นฐานด้านรัฐศาสตร์ (มหาวิทยาลัยรามคำแหง) สนใจงานด้านการประสานงานและติดตามความคืบหน้าโครงการ มีทักษะการประสานงานกับหลายฝ่าย การแบ่งงานและติดตามงาน การจัดทำรายงาน และการสร้างเครื่องมือช่วยงานด้วย Google Apps Script ซึ่งได้ฝึกใช้ผ่านงานผู้ประสานงานแขวงในโครงการภาครัฐ งานติดตามข้อมูลในพื้นที่ร่วมกับผู้นำชุมชน งานให้บริการข้อมูลประกันสังคม และงานฟรีแลนซ์ และกำลังมองหาโอกาสงานประจำในตำแหน่ง Project Coordinator

ผลงานเด่น

คัดเฉพาะงานที่เกี่ยวข้องกับการประสานงานโครงการ แต่ละชิ้นแยกให้เห็นว่าส่วนไหนเป็นงานที่ทำเอง และส่วนไหนเป็นงานของทีม

01

ผู้ประสานงานแขวง โครงการภาครัฐ

งานจริง คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ บางเขน · ก.ค.–ก.ย. 2565

บทบาท
ผู้ประสานงานแขวง ดูแลงานของแขวงที่ได้รับมอบหมาย
เป้าหมาย
รวบรวมและส่งมอบงานของแขวงให้คณะกรรมการส่วนกลางครบและตรงเวลา
ส่วนที่ทำเอง
แบ่งภาระงานให้ผู้ปฏิบัติงานในแขวง ติดตามความคืบหน้า ตรวจสอบงาน และส่งมอบงานให้ส่วนกลาง
ส่วนของทีม
คณะกรรมการส่วนกลางวางแผนและกำหนดแนวทางโครงการ ผู้ปฏิบัติงานในแขวงเก็บข้อมูลภาคสนาม
เครื่องมือ
[กรอกข้อมูล: เช่น Google Sheets, LINE กลุ่ม, แบบฟอร์มติดตามงาน]
ผลลัพธ์
[กรอกข้อมูล: เช่น จำนวนผู้ปฏิบัติงานที่ดูแล / จำนวนงานที่ส่งมอบ]

ทักษะที่ใช้: ประสานงานหลายฝ่าย · ติดตามงานและรายงาน

02

ติดตามและประสานงานปัญหาที่พักอาศัยในพื้นที่

งานจริง บัณฑิตจบใหม่ คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ บางเขน · ก.พ.–ธ.ค. 2564

บทบาท
เจ้าหน้าที่ติดตามและประสานงานในพื้นที่ (ตำแหน่งบัณฑิตจบใหม่)
เป้าหมาย
เก็บข้อมูลปัญหาที่พักอาศัยตามแบบฟอร์มของโครงการ และส่งต่อข้อมูลเพื่อใช้วางแผนช่วยเหลือ
ส่วนที่ทำเอง
ติดตามกรณีตามแบบฟอร์ม ประสานงานกับประธานหมู่บ้านและตำบลที่รับผิดชอบ บันทึกข้อมูล และจัดทำรายงานนำเสนอ
ส่วนของทีม
ทีมโครงการกำหนดแบบฟอร์มและนำข้อมูลไปใช้ต่อ ผู้นำชุมชนช่วยประสานกับครัวเรือนในพื้นที่
เครื่องมือ
[กรอกข้อมูล: เครื่องมือที่ใช้บันทึกและรายงานข้อมูล]
ผลลัพธ์
[กรอกข้อมูล: เช่น จำนวนครัวเรือน/พื้นที่ที่ติดตาม จำนวนรายงานที่จัดทำ]

ทักษะที่ใช้: ประสานงานหลายฝ่าย · ติดตามงานและรายงาน · ทำงานร่วมกับผู้นำชุมชน

ทักษะพร้อมหลักฐาน

แต่ละทักษะเชื่อมกับงานที่ได้ใช้จริง กดลิงก์เพื่อดูรายละเอียดของงานนั้น

ทักษะด้านงาน

  • ประสานงานหลายฝ่าย

    เป็นจุดกลางระหว่างคณะกรรมการ ผู้ปฏิบัติงาน และผู้นำชุมชน เพื่อให้งานเดินตามแผน

    หลักฐาน: ผู้ประสานงานแขวง · ติดตามปัญหาที่พักอาศัย

  • ติดตามงานและจัดทำรายงาน

    แบ่งงาน ติดตามความคืบหน้า บันทึกข้อมูล และสรุปเป็นรายงานส่งผู้รับผิดชอบ

    หลักฐาน: ผู้ประสานงานแขวง · ติดตามปัญหาที่พักอาศัย · งานบริการข้อมูลโครงการภาครัฐ

  • วางแผนและจัดตารางงาน

    จัดตารางการทำงานของพนักงาน วางแผนงานหน้าร้าน และสรุปยอดขายเป็นรายงาน

    หลักฐาน: Shop Supervisor เซ็นทรัล รีเทล

  • การบริหารความเสี่ยงและไทม์ไลน์โครงการ

    ทักษะที่ต้องใช้ในงาน Project Coordinator

    [เพิ่มผลงานที่แสดงทักษะนี้]

เครื่องมือ

  • Google Apps Script

    สร้าง Web App ใช้ Trigger และเชื่อมต่อ Google Workspace เพื่อลดงานที่ทำซ้ำ

    หลักฐาน: QTC Hub · SSO 1506 Simulator · งานฟรีแลนซ์

  • Gemini API

    ใช้ AI วิเคราะห์เอกสารและสร้างข้อความอัตโนมัติภายใน Web App

    หลักฐาน: QTC Hub

  • Google Workspace (Sheets, Docs, Forms, Drive)

    จัดเก็บข้อมูล ทำแบบฟอร์ม และแชร์เอกสารสำหรับทำงานร่วมกัน

    หลักฐาน: งานฟรีแลนซ์ด้านการจัดการข้อมูล · [เพิ่มผลงานที่แสดงทักษะนี้]

  • เครื่องมือบริหารโครงการ

    [กรอกข้อมูล: เช่น Trello, Asana, Notion, Excel Gantt chart]

    [เพิ่มผลงานที่แสดงทักษะนี้]

ทักษะการทำงานร่วมกับผู้อื่น

  • ทำงานร่วมกับผู้นำชุมชน

    ประสานกับประธานหมู่บ้านและตำบลเพื่อเข้าถึงข้อมูลในพื้นที่

    หลักฐาน: ติดตามปัญหาที่พักอาศัย

  • สื่อสารข้อมูลให้เข้าใจง่าย

    อธิบายสิทธิประกันสังคม เช่น กรณีว่างงานและสิทธิรักษาพยาบาล ให้ผู้ใช้บริการเข้าใจ

    หลักฐาน: งานบริการข้อมูลโครงการภาครัฐ · SSO 1506 Simulator

  • ดูแลและสอนงานพนักงานใหม่

    ดูแลการทำงานของพนักงานหน้าร้านและฝึกอบรมพนักงานใหม่

    หลักฐาน: Shop Supervisor เซ็นทรัล รีเทล

ประสบการณ์ทำงาน

  1. พ.ค.–ก.ค. 2568

    เจ้าหน้าที่ให้บริการข้อมูลโครงการภาครัฐ

    บริษัท ทรูทัช

    ให้ข้อมูลเรื่องประกันสังคม เช่น กรณีว่างงานและสิทธิรักษาพยาบาล ติดตามผลเรื่องที่รับไว้ และจัดทำรายงานสรุปข้อมูล

  2. 2566–ปัจจุบัน

    ฟรีแลนซ์ ระบบอัตโนมัติและจัดการข้อมูล

    Fastwork (งานอิสระ)

    รับงานสร้างระบบอัตโนมัติด้วย Google Apps Script จัดการข้อมูล และออกแบบเอกสารนำเสนอ

  3. พ.ค.–ก.ค. 2566

    Shop Supervisor (ผู้ช่วยผู้จัดการร้าน)

    บริษัท เซ็นทรัล รีเทล คอร์ปอเรชั่น จำกัด (มหาชน)

    ช่วยผู้จัดการวางแผนงาน จัดตารางงานพนักงาน ดูแลการทำงานหน้าร้าน ควบคุมสินค้า สรุปยอดขายและจัดทำรายงาน

  4. ก.ค.–ก.ย. 2565

    ผู้ประสานงานแขวง โครงการภาครัฐ

    คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ บางเขน

    แบ่งภาระงาน ติดตาม และส่งมอบงานของแขวงให้คณะกรรมการส่วนกลาง — ดูรายละเอียด

  5. ก.พ.–ธ.ค. 2564

    บัณฑิตจบใหม่ งานติดตามและประสานงานในพื้นที่

    คณะวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ บางเขน

    ติดตามปัญหาที่พักอาศัย ประสานงานกับผู้นำชุมชน บันทึกข้อมูลและทำรายงาน — ดูรายละเอียด

ประสบการณ์ด้านงานบริการและค้าปลีกก่อนหน้า
  • พนักงานประจำร้านสะดวกซื้อ Jiffy — บริษัท ปตท. บริหารธุรกิจค้าปลีก จำกัด (ก.ย. 2560–ก.พ. 2561): เปิดร้าน จัดเรียงและตรวจสต๊อกสินค้า แคชเชียร์
  • พนักงานร้านสะดวกซื้อ พาร์ทไทม์ — CP ALL FOOD HALL (ต.ค. 2557–เม.ย. 2559): บริการลูกค้า แคชเชียร์ รับชำระค่าสาธารณูปโภค
  • พนักงานเสิร์ฟอาหาร — บริษัท ใบไม้ร่าเริง จำกัด (ม.ค. 2549–ต.ค. 2552): รับออเดอร์ แนะนำเมนู ประสานงานกับครัว
